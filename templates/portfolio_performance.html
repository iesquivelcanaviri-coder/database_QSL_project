Portfolio Performance Review

This page replaces the old criteria explanation page with a database-backed portfolio performance dashboard. It compares portfolios using their saved holdings.

The purpose is to show which portfolios are doing well, which are mixed, and which need review based on average score, expected return, volatility, beta, allocation, and cash remaining.
