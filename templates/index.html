Portfolio Management Decision-Support Web Application with PostgreSQL

This application upgrades the previous in-memory Flask portfolio workflow into a fully database-backed system using PostgreSQL and Flask-SQLAlchemy.

The project demonstrates database integration, CRUD operations, Flask routing, SQLAlchemy ORM usage, HTML templating, responsive frontend design, and deployment-ready architecture.

Database-Backed Features

The application stores and retrieves data dynamically from a PostgreSQL relational database.

  • Portfolio mandates are stored as database records using the Portfolio model.
  • Ticker analysis results are stored as AnalysisRecord database entries.
  • Portfolio holdings support complete Create, Read, Update, and Delete (CRUD) functionality.
  • Contact form submissions are stored using the ContactMessage model.
  • Portfolio relationships are managed using SQLAlchemy foreign keys and ORM relationships.

How to Use the Application

  1. Review portfolio mandates and investor profiles on the Portfolio Profiles page.
  2. Screen and filter securities inside the Market Dashboard.
  3. Analyse a ticker using the Criteria page.
  4. Add holdings to a portfolio and verify that the data persists inside the PostgreSQL database.
  5. Update and delete holdings to demonstrate CRUD database functionality.
  6. Submit a contact message and verify that it appears dynamically on the Contact page.
