Portfolio Management Decision-Support Web Application with PostgreSQL

This Flask application demonstrates a database-backed portfolio management workflow using PostgreSQL, Flask-SQLAlchemy, Jinja templates, CSS, and JavaScript.

Main Workflow

  1. Create client portfolio profiles on the Portfolio Profiles page.
  2. Select a portfolio and stock on the Market Dashboard page.
  3. Save analysed stocks into the selected portfolio using database-backed CRUD logic.
  4. Review how each portfolio is doing on the Portfolio Performance page.

Database Features Demonstrated

  • Create: save new portfolio profiles and holdings.
  • Read: display profiles, dashboard data, holdings, and contact messages.
  • Update: update an existing holding when the same ticker is saved again.
  • Delete: remove saved holdings from a portfolio.
