Assign a Stock to a Portfolio Profile

This page connects the Portfolio Profiles page to the Portfolio Performance page.

First select a saved portfolio profile, then select a stock or ETF. When you click Analyse and Save Holding, the app sends the selected portfolio and ticker to the Flask /add-to-portfolio API route. The holding is saved in the database and then appears on the Portfolio Performance page.

What this dashboard does

This page helps a portfolio manager screen securities before assigning them to a portfolio. The table below can be filtered by ticker, decision, score, volatility, and Sharpe-like ratio.

The filtered table supports the investment workflow, while the form above performs the database-backed stock-to-profile assignment.

What each smart preset means

Low Risk: highlights more stable securities with lower volatility.

High Conviction: identifies the strongest investment ideas based on score and risk-adjusted performance.

Core Holdings: represents stable, well-balanced investments suitable for foundation positions.

Satellite / Diversifiers: includes supporting positions used to improve diversification.

Exploratory / High Risk: captures higher-risk ideas that should normally receive smaller allocations.

Income / Defensive: focuses on defensive or income-oriented securities.

Best Ranked: highlights securities with stronger dashboard scores.

Cash: represents cases where the security does not meet the investment criteria.
